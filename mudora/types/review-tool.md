# Review tools

**Marker:** `<meta name="mudora-type" content="review-tool">`
**Starter:** none yet; reuse `starters/base.css`

A page where several people leave comments, approve or answer, saved to the page's shared storage. Load the `artifact-capabilities` skill before changing how it saves. The interactive rules in [components.md](../components.md#interactive-pages-review-tools-answerable-cards) apply in full.

## Checklist

- Is there a pinned, semi-transparent reminder while work is unsent, and no toast repeating it?
- Can a reviewer hide everyone else's input, with viewed/approved still shown?
- Does every control stay put when text next to it changes?
- Are people who share a status grouped into one line?
